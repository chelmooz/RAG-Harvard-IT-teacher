# Crédits / Remerciements

Ce projet réutilise du code et des recherches issus de la communauté AMD BC-250.
Tous les dépôts listés ci-dessous sont sous licence **MIT** ; seuls les auteurs
sont cités en remerciement (aucune modification de paternité).

## Optimisation BC-250 (dossier `scripts/bc250/`, `scripts/bazzite/`)

| Auteur / dépôt | Apport vendored | Licence |
|----------------|-----------------|---------|
| **WinnieLV** / [bc250-cu-live-manager](https://github.com/WinnieLV/bc250-cu-live-manager) | Déblocage 40 CU via UMR (`40cu-unlock/`) | MIT |
| **bc250-collective** / [bc250_smu_oc](https://github.com/bc250-collective/bc250_smu_oc) | UV/OC CPU via SMU (`smu-oc/`) | MIT |
| **keyboardspecialist** / [bc250-steamos](https://github.com/keyboardspecialist/bc250-steamos) | Déblocage 8 cœurs Zen2 (`core-unlock/`), split RAM/VRAM | MIT |
| **rpf16rj** / [bc250-steamos-real-toolkit](https://github.com/rpf16rj/bc250-steamos-real-toolkit) | Recherche SMU/toolkit (référence) | MIT |
| **MastaG** / [linux-cachyos-bc250](https://github.com/MastaG/linux-cachyos-bc250) | Patches noyau 0001-0009 (Phase 2 opt-in, non vendored) | MIT |
