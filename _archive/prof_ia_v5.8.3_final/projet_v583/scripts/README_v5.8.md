## 🚀 Démarrage Ultra-Rapide

### 1. Vérifier les datasets

```bash
ls kaggle_datasets/      # 4 datasets
ls huggingface_datasets/ # 3 datasets
```

### 2. Installer les dépendances

```bash
pip install -r requirements_import.txt
```

### 3. Lancer l'import (2-4h)

**Windows** :
```powershell
.\import_all_datasets.ps1
```

**Linux/Mac** :
```bash
chmod +x import_all_datasets.sh
./import_all_datasets.sh
```

### 4. Intégrer dans v5.7

Suivez le **GUIDE_INTEGRATION_v5.8_ALL_IN_ONE.md**

## 📊 Architecture ALL-IN-ONE

```
prof_ia_all (UNE seule collection universelle)
├── TSSR        : ~11 000 chunks (support)
├── AIS         : ~16 700 chunks (sécurité) ⭐
├── DevOps      : ~5 300 chunks (CI/CD)
└── Transverse  : ~200 chunks (Linux)
────────────────────────────────────────────
TOTAL           : ~33 000 chunks (~3.9 GB)
```
